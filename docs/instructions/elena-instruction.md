## Создание папки с чатами в Telegram.

В Telegram вы можете создать одну или несколько папок с чатами.

1. Перейдите в раздел **Главное меню**.
2. Выберете раздел **Настройки**.
3. Перейдите в подраздел **Папка с чатами**.
4. Нажмите на кнопку **Создать новую папку**.
5. Введите название папки.
6. Нажмите на кнопку **Добавить чаты**, выберите один или несколько чатов и нажмите на кнопку Сохранить.
7. Вы можете добавить исключенные чаты, выбрать цвет папки или добавить теги для чатов.
*Примечание. Цвет папки и теги для чатов доступны только для пользователей с подпиской Telegram Premium*.
8. Нажмите на кнопку **Создать**.

## При необходимости Вы можете создать ссылку-приглашение на папку.

### Для этого:
1. Выберите папку, для которой хотите создать ссылку-приглашение или создайте новую.
3. Нажмите **Создать ссылку-приглашение**;
4. Нажмите **Копировать** или **Поделиться**:
* при выборе Копировать - ссылка будет скопирована в буфер обмена;
* при выборе Поделиться - отобразится список чатов, с которыми можно поделиться ссылкой-приглашением.
5. Нажмите **Готово**.
