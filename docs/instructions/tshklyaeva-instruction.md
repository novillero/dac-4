# Как использовать стили текста в Telegram: полное руководство

## Введение

Telegram поддерживает [несколько стилей](#какие-стили-доступны) оформления текста: **жирный**, *курсив*, <u>подчёркнутый</u>, ~~зачёркнутый~~, `моноширинный`, ||спойлер||, цитаты, ссылки и форматирование дат. Стили можно применять двумя способами: через [всплывающее меню](#меню-форматирования) и [горячими клавишами](#горячие-клавиши).

---

## Какие стили доступны

| Стиль | Назначение | Пример |
|-------|-----------|--------|
| **Жирный** | Заголовки, акценты | **важный текст** |
| *Курсив* | Выделение, цитаты по смыслу | *обратите внимание* |
| <u>Подчёркнутый</u> | Дополнительный акцент | <u>подчёркнуто</u> |
| ~~Зачёркнутый~~ | Старая цена, отмена | ~~1000 ₽~~ |
| `Моноширинный` | Код, команды, технические данные | `git status` |
| > Цитата | Ссылка на чужой текст, ключевая мысль | > фрагмент |
| Ссылка | Кликабельное слово вместо URL | [сайт](https://example.com) |
| Дата | Кликабельная метка времени | 15 марта, 14:00 |

В Telegram **нельзя** изменить цвет текста, размер шрифта или сам шрифт — доступны только перечисленные стили.

---

## Добавление стилей

### Меню форматирования

Самый универсальный способ — работает на всех устройствах.

**Шаги:**

1. Напишите сообщение в поле ввода, но **не отправляйте**.

2. Выделите нужный фрагмент текста.

3. В появившемся меню над выделением выберите стиль.

На **Android** меню может прятаться под тремя точками в правом верхнем углу.

На **iOS** нажмите стрелку в конце меню выделения и выберите «Форматирование».

На **десктопе** щёлкните правой кнопкой по выделенному тексту и выберите «Форматирование».

### Горячие клавиши

| Стиль | Windows / Linux | macOS |
|-------|-----------------|-------|
| Жирный | `Ctrl + B` | `⌘ + B` |
| Курсив | `Ctrl + I` | `⌘ + I` |
| Подчёркнутый | `Ctrl + U` | `⌘ + U` |
| Зачёркнутый | `Ctrl + Shift + X` | `⌘ + Shift + X` |
| Моноширинный | `Ctrl + Shift + M` | `⌘ + Shift + M` |
| Спойлер | `Ctrl + Shift + P` | `⌘ + Shift + P` |
| Ссылка | `Ctrl + K` | `⌘ + K` |
| Цитата | `Ctrl + Shift + .` | `⌘ + Shift + .` |
| Дата | `Ctrl + Shift + D` | `⌘ + Shift + D` |
| Сбросить формат | `Ctrl + Shift + N` | `⌘ + Shift + N` |
