# ^^Руководство по отправке отложенного приложения в Телеграмм.^^

!!! info "Информация"
    Эта инструкция создана в рамках мастер-класса по docs as code.

!!! note "Примечание"
    Инструкция предназначена для отправки отложенного сообщения через приложение Telegram на вашем смартфоне.

*1.* Выберите адресата или группу.
*2.* Наберите текст в поле внизу открывшегося окна.
*3.* Зажмите круглую синюю кнопку справа от поля ввода текста. Откроется контекстное выпадающее меню.
*4.* Выберите "Отправить позже".
*5.* Выставите день и время отправки.
*6.* Задайте периодичность отправки в нижней части открывшегося окна.
*7.* Нажмите на колокольчик в правом верхнем углу. Если колокольчик перечёркнут, адресат получит сообщение без уведомления.
*8.* Для настройки отправки отложенного сообщения при появлении адресата в сети, нажмите на три точки в правом верхнем углу. Появится вкладка "При появлении адресата в сети". Выбираем данную вкладку.
*9.* Откроется окно отложенной отправки. Введите  ваше сообщение.
