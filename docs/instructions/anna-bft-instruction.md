# Краткая инструкция по работе с папками в Telegram

**Telegram** (или «Телеграм») — это кроссплатформенный мессенджер для обмена сообщениями и медиафайлами, а также для голосовых и видеозвонков.

Эта инструкция создана в рамках мастер-класса по docs as code.

## Основные возможности
* **Переписка:** текстовые сообщения, голосовые и видеосообщения, стикеры, эмодзи, GIF.
* **Медиа и файлы:** отправка фото, видео, документов — в том числе довольно больших (до нескольких гигабайт в зависимости от типа аккаунта).
* **Групповое общение:** групповые чаты (до 200 000 участников) и каналы для публикации контента на неограниченную аудиторию.
* **Боты:** автоматизированные аккаунты, которые помогают решать разные задачи — от напоминаний и конвертации файлов до интеграции с рабочими сервисами.
* **Каналы и публикации:** можно вести микроблоги, новостные рассылки, обучающие серии и т. п.
* **Звонки:** аудио- и видеозвонки, в том числе групповые.
* **Облачные чаты и мультиустройство:** чаты синхронизируются между устройствами; можно сидеть в Telegram одновременно на телефоне, планшете и компьютере.
* **Секретные чаты:** с `end‑to‑end` шифрованием и возможностью автоудаления сообщений.

## 1. Установка программы

### Шаг 1. Скачайте установочный файл
* Откройте браузер и перейдите на [официальную страницу загрузок](https://desktop.telegram.org/).
* Сайт автоматически определит вашу операционную систему (`Windows`, `macOS` или `Linux`). Если он ошибся, нажмите **«Показать все платформы»** и выберите подходящую версию вручную. 
* Нажмите кнопку загрузки. Для `Windows` скачается `.exe`-файл, для `macOS` — образ `.dmg`, для `Linux` — архив. 

### Шаг 2. Установите приложение

**Windows.** Запустите скачанный файл. При первом запуске выберите язык интерфейса. Затем укажите папку для установки (можно оставить стандартную) и решите, создавать ли ярлыки на рабочем столе и в меню «Пуск». Нажмите «Установить» и дождитесь завершения. 

**macOS.** Откройте скачанный .dmg-файл и перетащите иконку Telegram в папку «Программы» (Applications). При первом запуске система может запросить разрешение — нажмите «Открыть». 

**Linux.** Есть несколько вариантов: 
- **Flatpak:** flatpak install flathub org.telegram.desktop, запуск — `flatpak run org.telegram.desktop`. 
- **Snap** (для Ubuntu и производных): `sudo snap install telegram-desktop`. 
- **AppImage:** скачайте файл, сделайте его исполняемым (`chmod +x telegram-desktop*.AppImage`) и запустите. 

### Шаг 3. Авторизуйтесь
После установки запустите приложение. Самый быстрый способ — войти через QR-код:
- На экране компьютера появится QR-код.
- Откройте мобильное приложение Telegram, зайдите в «Настройки» → «Устройства» (или «Связать устройство») и отсканируйте код камерой.
 
Если телефона под рукой нет, выберите «Войти по номеру телефона». Код подтверждения придёт в мобильное приложение или по SMS. 

### Несколько советов
**Антивирус.** Иногда защитное ПО блокирует запуск. Проверьте, что у файла есть цифровая подпись от Telegram FZ-LLC — в большинстве случаев это ложное срабатывание.
**Альтернатива.** Если не хотите устанавливать приложение, можно открыть веб-версию в браузере по адресу web.telegram.org.

## 2. Работа с папками в приложении Telegram

### 2.1. Как создать папку
1. Откройте боковую панель Telegram (нажмите на три полоски в левом верхнем углу). 
2. В самом низу меню найдите и выберите пункт **«Папки»**. 
3. Нажмите **«Создать новую папку»**. 
4. Придумайте название (максимум 12 символов). 
5. В блоке **«Включить чаты»** добавьте нужные диалоги или целые типы: **«Контакты»**, **«Группы»**, **«Каналы»**, **«Боты»**. Можно также выбрать **«Непрочитанные»** (только чаты с новыми сообщениями) или **«Закреплённые»**. 
6. В блоке **«Исключённые чаты»** можно убрать из папки конкретные диалоги. 
7. Нажмите «Сохранить». 

После этого папка появится как отдельная вкладка в списке чатов. 

### 2.2. Дополнительные настройки
После создания папки можно её кастомизировать:
- **Изменить порядок**. Зажмите название папки и перетащите её вверх или вниз. 
- **Выбрать иконку**. В настройках папок (в меню сбоку) можно назначить иконку для каждой вкладки из предложенных эмодзи. 
- **Выбрать расположение**. По умолчанию вкладки отображаются слева, но можно изменить это на **«Над чатами»**. 
- **Поделиться папкой**. Зажмите название папки и выберите **«Поделиться»**, чтобы отправить ссылку-приглашение другим пользователям. 

### 2.3. Управление папками
- **Добавить чат**. После создания папки можно добавлять в неё чаты прямо из общего списка: кликните правой кнопкой манипулятора на чате и выберите **«Добавить в папку»**.
- **Удалить папку**. В контекстном меню папки выберите **«Удалить папку»**.
 
#### 2.3.1. Важные нюансы
* Один и тот же чат можно добавить в несколько папок. 
* В одну папку можно добавить до 100 чатов (для пользователей Telegram Premium — до 200). 
* Папки автоматически синхронизируются между всеми устройствами, где выполнен вход в ваш аккаунт. 
* Стандартная папка **«Все чаты»** всегда остаётся в списке — её нельзя удалить или переименовать. 

#### 2.3.2. Что делать, если функция не видна
Если в меню **«Папки»** нет пункта, скорее всего, у вас устаревшая версия приложения. Проверьте, что Telegram обновлен. 

### Советы по организации
* Начните с 3–4 понятных папок (например, «Работа», «Личное», «Новости»).
* Не бойтесь редактировать структуру: если что-то не так, просто измените настройки папки.
