# Краткая инструкция по работе с Notepad++

**Notepad++** — это текстовый редактор для Windows, который особенно любят разработчики: он поддерживает подсветку синтаксиса, регулярные выражения, плагины и многое другое.

## 1. Установка программы

### 1.1. Скачайте установщик 
**Шаг 1.** Перейдите на [официальную страницу загрузок](https://notepad-plus-plus.org/). Найдите и нажмите кнопку «Скачать» рядом с текущей стабильной версией. 
**Шаг 2.** Выберите правильный файл. Это важный шаг. Посмотрите тип вашего процессора:
- если у вас процессор x64 (большинство современных ПК и ноутбуков) — скачивайте файл с названием вроде Installer.x64.exe;
- если процессор ARM (некоторые ноутбуки и планшеты) — нужен Installer.arm64.exe.

Не берите версию x86 для современных Windows 10/11 — она не подойдёт. 

### 1.2. Запустите установщик
Откройте скачанный файл. Если система запросит разрешение — подтвердите (обычно это нужно для записи в системные папки). 
Следуйте шагам мастера:
- Выберите язык установки.
- Примите лицензионное соглашение.
- Оставьте папку установки по умолчанию (обычно Program Files) или укажите другую, если есть особые причины. 
- В разделе выбора компонентов оставьте настройки по умолчанию, если не знаете, что именно вам нужно. 
- При желании создайте ярлыки на рабочем столе или в меню «Пуск».
- Нажмите «Установить» и дождитесь завершения. 

В конце можно оставить галочку «Запустить Notepad++», чтобы сразу открыть редактор. При первом запуске вы увидите чистый редактор с меню сверху и вкладками для файлов.

### 1.3. Несколько советов
- **Безопасность.** Если SmartScreen в Windows выдаст предупреждение, не пугайтесь сразу. Проверьте, что файл действительно с официального сайта, и сверьте контрольную сумму (SHA-256), если она опубликована в разделе загрузок. 
- **Права администратора.** Для полноценной установки (и позже — для обновления или установки плагинов) обычно требуются права администратора. Если на рабочем компьютере нет таких прав, обратитесь к системному администратору. 
- **Режим Windows 11 S.** В режиме S Windows внешние установщики могут блокироваться. В этом случае придётся временно выйти из этого режима. 
- **Если установка не удалась.** Например, если система сообщает, что какие-то файлы уже используются, закройте все открытые экземпляры Notepad++ (если они были) и попробуйте запустить установщик ещё раз. 

## 2. Базовые операции
* Открыть файл: `Файл → Открыть` или `Ctrl+O`
* Создать новый файл: `Файл → Создать` или `Ctrl+N`
* Сохранить / Сохранить как: `Ctrl+S`, `Ctrl+Shift+S`
* Закрыть вкладку: 	`Ctrl+W`
* Выделить всё: 	`Ctrl+A`
* Копировать / Вырезать / Вставить: `Ctrl+C`, `Ctrl+X`, `Ctrl+V`

## 3. Настройка кодировки и формата конца строк
Для корректной работы с кодом и скриптами важно следить за этими параметрами:
- **Кодировка:** в меню `Кодировки` выберите требуемую, например, `UTF-8` (лучше без BOM).
- **Формат конца строк:** в меню `Правка → Формат конца строки` выберите `Unix (LF)` для Linux/Git или `Windows (CRLF)` для Windows. Это важно, чтобы скрипты (в том числе VBA) не ломались из-за разных переносов строк.

## 4. Подсветка синтаксиса и язык файла
Notepad++ автоматически определяет язык по расширению файла (`.txt`, `.xml`, `.json`, `.vba`, `.sql` и т.д.). Если подсветка не та, выполните один из вариантов, предложенных ниже:
1. В меню Язык выберите нужный язык (например, `VBA`, `SQL`, `XML`).
2. На панели инструментов нажмите на выпадающий список языков и выберите вручную.

Это поможет видеть ключевые слова, комментарии и строки цветом — так проще читать и находить ошибки.

## 5. Поиск и замена (включая регулярные выражения)
Это одна из самых мощных функций Notepad++
- Поиск: `Ctrl+F`
- Замена: `Ctrl+H`

### 5.1. Регулярные выражения (Regex)
В окне «Заменить» (или «Найти») включите режим `Регулярное выражение` (флажок внизу). Примеры:
- Найти все слова, оканчивающиеся на точку (как «руб.»): `\b\w+\.\b`
- Найти строки, где есть только латиница и цифры: `^[A-Za-z0-9]+$`
- Удалить пустые строки: найти `^\s*$\n?`, заменить на пусто.

Регулярные выражения очень пригодятся, если вы работаете с текстами для последующей обработки в VBA или очисткой данных.

## 6. Работа с несколькими файлами и вкладками
* Файлы открываются в вкладках — можно держать сразу несколько документов.
* Переключаться между вкладками: `Ctrl+Tab` / `Ctrl+Shift+Tab`.
* Чтобы быстро найти текст во всех открытых файлах: `Поиск → Найти в файлах` (`Ctrl+Shift+F`). Укажите папку, маску файлов (например, `*.vba`) и текст для поиска.

## 7. Форматирование и полезные операции с текстом
* **Преобразовать регистр:** выделите текст, затем `Правка → Операции с регистром` (верхний / нижний / заглавные буквы и т.д.).
* **Удалить начальные/конечные пробелы:** `Правка → Удалить начальные и конечные пробелы`.
* **Сортировать строки:** `Правка → Операции со строками → Сортировать строки по возрастанию/убыванию`.
* **Дублировать строку:** `Ctrl+D`.
* **Переместить строку вверх/вниз:** `Ctrl+Shift+↑` / `Ctrl+Shift+↓`.

## 8. Плагины и расширения
Notepad++ поддерживает плагины, которые добавляют новые возможности. Для установки плагинам выполните следующие действия:
1. Откройте `Плагины → Управление плагинами`.
2. Найдите и установите нужные (например, `NppExec` для запуска внешних команд, `Compare` для сравнения файлов).

После установки перезапуск обычно не требуется.

## 9. Автодополнение и сниппеты
* Автодополнение работает для популярных языков (появляется при вводе части слова).
* Можно создавать свои шаблоны через меню `Плагины` или вручную через файлы сниппетов (если нужно часто вставлять одни и те же фрагменты кода).

## Несколько практических советов
Если вы готовите или редактируете VBA-код либо обрабатываете текстовые данные для макросов:
1. **Всегда сохраняйте в UTF‑8** и следите, чтобы не было лишних BOM, если файл будет читаться другими инструментами.
2. **Используйте поиск с регулярными выражениями**, чтобы быстро находить шаблоны вроде слов с точкой, сокращений, слов с дефисом и т.д.
3. **Сравнивайте файлы** (через плагин Compare), когда нужно увидеть, что изменилось между версиями макроса.
4. **Проверяйте формат конца строк**, если скрипт ломается при переносе между системами.
