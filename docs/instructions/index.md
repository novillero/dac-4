#Создание списка задач
*Доступно в Premium*
1. Откройте Telegram
2. Откройте нужный диалог
3. Нажмите символ "Скрепка" и в открывшемся меню выберите тип "Список"
3.1 Введите название списка
3.2 Введите необходимые задачи. Для добавления строк нажмите "Добавить задачу"
3.3 Активируйте переключатель совместного выполнения или добавления задач
4. Нажмите кнопку "Создать"
