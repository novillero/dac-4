**Пользовательский сценарий: "Отправить отложенное сообщение"**

**Цель:** пользователь хочет написать сообщение сейчас, но отправить его в выбранные дату и время.

**Шаг 1. Открыть Telegram**

Пользователь запускает приложение Telegram

**Шаг 2. Открыть нужный чат**

Пользователь выбирает чат, группу или канал, в котором необходимо отправить сообщение.

**Шаг 3. Написать сообщение**

В поле ввода пользователь вводит текст сообщения. При необходимости добавляет фото, видео, файл, ссылку.

**Шаг 4. Открыть меню отправки**

Пользователь нажимает и удерживает кнопку **«Отправить»**.

**Шаг 5. Выбрать отложенную отправку**

В открывшемся меню пользователь выбирает пункт «Отправить позже» / «Запланировать сообщение».

**Шаг 6. Выбрать дату**

Пользователь выбирает дату, когда сообщение должно быть отправлено.

**Шаг 7. Выбрать время**

Пользователь устанавливает необходимое время отправки.

**Шаг 8. Подтвердить отправку**

Пользователь нажимает **«Запланировать»**.

**Шаг 9. Проверить запланированное сообщение**

Сообщение не появляется в обычной переписке как отправленное. Оно сохраняется в разделе запланированных сообщений с указанием установленной даты и времени.

**Шаг 10. Автоматическая отправка**

В установленное время Telegram автоматически отправляет сообщение в выбранный чат.
